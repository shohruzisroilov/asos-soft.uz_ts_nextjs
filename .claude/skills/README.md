# Claude Code Skills

Shared design skills for this project. They load automatically when working in this
repo with Claude Code — no install step, just pull the branch.

| Skill | Purpose |
|-------|---------|
| `frontend-design` | Aesthetic direction, typography, and layout guidance for building or reshaping UI. |
| `ui-ux-pro-max` | Searchable design database: 84 styles, 192 palettes, 74 font pairings, 98 UX guidelines, 25 chart types, 22 stacks. |

## ui-ux-pro-max queries

Requires `python3` (no extra packages). Run from the repo root:

```bash
# Full design system recommendation — start here for a new page
python3 .claude/skills/ui-ux-pro-max/scripts/search.py "saas landing page" --design-system

# Search one domain: style, ux, color, typography, chart, icon, motion
python3 .claude/skills/ui-ux-pro-max/scripts/search.py "dark mode" --domain style

# Stack-specific guidelines (this project: nextjs)
python3 .claude/skills/ui-ux-pro-max/scripts/search.py "server components" --stack nextjs
```

`--persist -p "Project Name"` writes a `design-system/` folder; it is gitignored.

## Updating

`ui-ux-pro-max` is generated by its CLI:

```bash
npx ui-ux-pro-max-cli@latest init --ai claude --force
```

Note that regenerating **overwrites `SKILL.md` and re-adds skills we do not use.**
The committed `SKILL.md` carries local fixes over the generated output:

- script paths corrected to `.claude/skills/...` (generated ones are broken from the repo root)
- database counts corrected to match the actual CSVs (the template ships stale numbers)
- untranslated sections translated to English

After regenerating, re-apply those and delete the extra skill folders the CLI adds
(`banner-design`, `brand`, `design`, `design-system`, `slides`, `ui-styling`).
